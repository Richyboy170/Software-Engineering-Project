Repeatable procedure

  1. Create and review a feature PR into sprint-1-staging; test-and-docker must pass.
  2. Open an approved release PR from sprint-1-staging to main.
  3. Merge into main; the deploy workflow is restricted to the demo environment and main.
  4. GitHub Actions authenticates with WIF, builds the full-SHA tag, resolves its digest, runs migration, deploys Cloud Run, and smoke-tests the public URL.
  5. Verify the running revision and image with Cloud Run, and verify the workflow commit, SHA tag and digest in GitHub Actions.

Rollback identification

A rollback uses a previous full 40-character commit SHA. deploy/release.sh validates the SHA, redeploys the image tag, and skips migration unless normal release mode is selected. The rollback image may be identified by the deployed image digest and Cloud Run revision.
